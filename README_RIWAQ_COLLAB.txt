RIWAQ technical source snapshot

This archive contains the tracked source files for RIWAQ at the time of packaging. It excludes runtime secrets and local environment files. The deployed site and its database remain managed separately by the site owner.

To work on the source locally:
1. Extract the archive.
2. Install Node.js 22.13+ and pnpm 11.25+.
3. Run the repository setup/dependency instructions in docs/RUNBOOK.md.
4. Never place real provider keys in source files or this archive.

This package is a source snapshot, not a connected Git collaboration remote. Changes made here do not automatically publish to the live Site. Coordinate proposed changes with the owner before deployment.
